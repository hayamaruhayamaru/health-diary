# 健康記録 (health-diary)

症状・服薬・気づいたことをブラウザ内に記録するためのwebアプリケーションです。

体調の主観評価（つらさ）と実測値（体温など）、服薬時刻、備考を記録し、
診察時に共有しやすい形で書き出すことを目的としています。

## 主な機能

- **記録 (01)** — 日付ごとに症状（つらさ 0〜10／実測値）と服薬チェック、備考を記録
- **履歴 (02)** — カレンダー、推移グラフ、過去記録一覧から日付を選んで編集
- **薬 (03)** — 服薬する薬と症状を登録することで簡単に管理
- **入出力 (04)** — Excel / CSV / PDF / 印刷でのエクスポートと、Excel / CSVからの取り込み
- **データの取り扱いについて (05)** — 保存場所、データ消失リスク、バックアップ手順の案内

### データ保存方針

データは**ブラウザのローカルストレージ**にのみ保存され、外部サーバーには送信されません。
以下の操作でデータが失われる可能性があるため、こまめに Excel 等でのバックアップを推奨します。

- ブラウザの「Cookie とサイトデータ」を削除したとき
- プライベート／シークレットウィンドウで使用したとき
- 別のブラウザ／端末／ユーザーから開いたとき
- ブラウザをアンインストールしたとき

## エクスポート形式

| 形式 | 内容 |
| --- | --- |
| Excel | 「症状記録」「服薬記録・備考」の2シート構成 |
| CSV | 1ファイルに横並びで出力（UTF-8 BOM 付き） |
| PDF | ブラウザ描画を画像化（日本語の文字化けなし） |
| 印刷 | ブラウザの印刷ダイアログを起動 |

入力フォーマット（テンプレート）も同梱しており、ダウンロード→記入→取り込みで再インポートできます。

## 技術スタック

- React 19 + TypeScript
- Vite
- Tailwind CSS
- xlsx（SheetJS）／ jsPDF ／ html2canvas

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド
npm run preview  # ビルド成果物のプレビュー
```

開発サーバー起動後、表示された URL（既定は `http://localhost:5173/health-diary/`）をブラウザで開いてください。

## ディレクトリ構成

```
src/
  components/    画面構成コンポーネント

  lib/           インポート・エクスポート処理
  types.ts       型定義
  index.css      グローバルスタイル
```
